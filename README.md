# ud01_proyect-alvaro
A program that converts € to $
## How to run it
```bash
python3 src/main.py
```
## Example
```text
Introduce la cantidad en EUR: 7843
7843.0 EUR = 8470.44 USD
```
## Project structure
- `src/`: here is main.py
- `tests/`: here will be the tests of the projects
- `data/`: here will be all the data of the projects
- `docs/`: here will be the documentation
